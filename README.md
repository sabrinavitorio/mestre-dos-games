# MESTRE DOS GAMES - Loja virtual de games

Projeto acadêmico de Desenvolvimento Web com homepage e carrinho de compras demonstrativo.

## Arquivos
- `index.html`: página principal da loja.
- `carrinho.html`: página do carrinho.
- `style.css`: estilos das duas páginas.
- `script.js`: funcionalidades em JavaScript.
- `imagens/`: imagens fornecidas pelo grupo.

## Como executar
1. Extraia a pasta do projeto.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).
4. Clique em **Adicionar ao carrinho** para incluir jogos.
5. Abra **Carrinho** no cabeçalho para alterar quantidades, remover itens e testar o cupom.

## Funcionalidades implementadas
- Adicionar produtos ao carrinho.
- Persistir os itens no navegador com `localStorage`.
- Atualizar o contador de itens.
- Aumentar e diminuir quantidades.
- Remover produtos.
- Calcular subtotal, desconto e total.
- Cupom `MESTRE10`, que aplica 10% de desconto.
- Botão de finalizar compra demonstrativo (não processa pagamento real).

## Conteúdos de JavaScript utilizados
Variáveis, tipos de dados, arrays, operações matemáticas, funções, condicionais, repetição com `map`/`reduce`, eventos, manipulação do DOM e armazenamento local.

## Observações
Os produtos e valores são fictícios para fins acadêmicos. Duas capas de produtos são representações gráficas feitas em CSS porque o material recebido continha apenas duas imagens de jogos. O checkout é demonstrativo e não coleta dados nem realiza pagamentos.

**Tecnologias:** HTML5, CSS3 e JavaScript.
